# devops-capstone-project

A Customer Accounts RESTful microservice built with Python and Flask for the IBM DevOps and Software Engineering capstone project.

The service manages customer account data (name, email, address, phone number and date joined) and exposes a REST API to create, read, update, delete and list accounts. It is developed with test-driven development, integrated with GitHub Actions CI, packaged in Docker, and deployed to OpenShift with a Tekton CD pipeline.
